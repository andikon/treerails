# Worktree-first release target

The accepted TUI centers Project → Worktree → Conversation. Projects open as top tabs. The stable left worktree column is followed by a Sessions or Changes list, with the actual Copilot CLI or Git diff on the right. One segmented bottom line shows branch, tracking, path, commit and agent status. Creation uses small local + controls; secondary commands and shortcuts live in Help. The normal screen has no shortcut footer or repeated worktree header.

New worktrees and new sessions are separate operations. The session + immediately opens an empty Copilot CLI conversation on the selected worktree, without a Tree Rail setup form. Optional combined session/worktree creation remains in Help. Every newly created worktree defaults to the fetched actual remote default branch, with explicit overrides including the selected checkout's HEAD. Worktree rows show added/removed line totals against HEAD, including untracked text; staged and unstaged changes are not double-counted. First Push publishes and sets upstream. Git writes wait while an agent turn owns that worktree, including input waits. Removing a worktree requires a clean idle linked checkout and keeps its branch.

Multiple saved conversations belong directly to each worktree. Copilot is the first AHP provider. Tree Rail owns a temporary SDK runtime and observes AHP state; the real CLI attaches to the same conversation in a child terminal and owns its live interface. The first prompt is optional. Ctrl+] returns to Tree Rail navigation; all other focused input belongs to Copilot. Switching views preserves terminal processes, closing a terminal disconnects only its frontend, and closing a project tab hides active sessions after confirmation. Quitting closes child terminals and stops owned runtime work. Restart restores identity and cached history without starting agents or replaying prompts; live drafts belong to Copilot. Missing checkouts retain read-only history. Local archive is reversible.

Configuration contains declared preferences and sources. A separate sibling state file stores runtime memory. Both load before the first frame. On Windows both live under Local AppData; Unix uses the configured application directory. Migrate the previous combined document with a complete backup. Ticket/task/issue/discussion orchestration and the persistent terminal host are removed; their ADRs and earlier research remain historical.

The visual target was approved on 2026-10-21.
